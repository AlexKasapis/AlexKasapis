### Senior C#/.NET backend engineer and technical lead

I build backend systems that have to stay up: real-time services running 24/7 at more than 99.99% uptime, high-load APIs tuned until they fit on smaller cloud tiers, and LLM features that hold up in production.

I lead 12 engineers on a B2B sportsbook and casino platform and stay hands-on in architecture, code and on-call. Based in Thessaloniki, Greece.

#### Selected work

**[Keyhole](https://github.com/AlexKasapis/Keyhole)** · Rust · open source  
A terminal UI for message and data brokers. Browse Redis, AMQP 1.0 (ActiveMQ, Amazon MQ, RabbitMQ 4.x) and RabbitMQ, watch live activity, and record streams to disk. One self-contained binary, with CI and at least 90% test coverage.

**ProjectSim** · C# · private  
A data-oriented ECS simulation engine written from scratch. Unmanaged storage and allocation-free hot paths reach about 9.4 million entity updates per second on a single worker, with identical results at any thread count. Game rules are defined as data, and a headless server streams the world to an OpenGL client.

**Leadbot** · .NET, React, PostgreSQL with pgvector · private, co-built  
An AI product that answers a business's inbound leads across social and messaging channels. An LLM pipeline with retrieval and evals drafts replies from CRM-synced listings for a person to approve, gathers details, scores leads and schedules follow-ups. In alpha.
